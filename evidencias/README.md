O arquivo [resumo.json](resumo.json) reúne a contagem de testes e a cobertura medida.

Para visualizar os relatórios HTML de cobertura, baixe o repositório e abra o arquivo `index.html` de cada projeto dentro de `cobertura`. O GitHub exibe o código do HTML, sem executar a página.

Os logs foram convertidos para UTF-8 para facilitar a leitura no GitHub. Os caminhos locais registrados correspondem ao ambiente em que os testes foram executados.
